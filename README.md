# Bac TN+

Plateforme tunisienne de préparation au baccalauréat.

## Démarrage

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

### ملاحظة
هذه النسخة هي واجهة البداية. الخطوة التالية هي ربط الواجهة ببيانات Supabase الحقيقية (الشعب → المواد → الفصول → الدروس → التمارين → QCM → النتائج والتقدم).
